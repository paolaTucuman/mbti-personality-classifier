# Datos de la encuesta

`Datos_pr.csv` fue entregado por el docente del módulo FML del diplomado de la UPB para el proyecto final. La fuente original y el periodo de recolección no constan en los materiales disponibles.

El archivo contiene **59.999 registros** y **62 columnas**: un identificador consecutivo (`Response Id`), 60 respuestas a afirmaciones de la encuesta y la etiqueta `Personality`, que toma 16 valores. Las respuestas numéricas van de −3 a 3. No se detectaron valores faltantes en este archivo.

El identificador se excluye del modelado porque no representa una respuesta. El conjunto permite evaluar qué tan bien se reproducen sus etiquetas a partir de las respuestas; la procedencia y la forma de asignar esas etiquetas no están documentadas, por lo que el resultado no debe interpretarse como una prueba de validez de los tipos de personalidad ni como desempeño esperado fuera de este conjunto.
